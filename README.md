# ObjPirmaUzduotis
 
v0.1(vector, C masyvai, mišrus): Programos leidžia vartotojui gauti galutinį studentų įvertinimą, naudojant vidurkį ar medianą. Vartotojas gali įvesti duomenis ranka(studentų vardus, pavardes, pažymius ir egzaminų įvertinimus), taip pat galimas pasirinkimas generuoti studentų pažymius arba generuoti ir studentų pažymius, ir jų vardus bei pavardes.

Visos 3 programos (vector, masyvo ir mišri) turi tokią pačią vartotojo sąsają. Skiriasi duomenų saugojimo būdai.
